Website Planning Document

Site Name

Jinja Tourism Hub

This name was chosen because the website focuses on providing tourism information about Jinja District, Uganda, including attractions and activities.

Optional domain: jinjatourismhub.com

Site Purpose

The purpose of this website is to inform visitors about tourism in Jinja District. The site will provide information about popular tourist attractions, adventure activities, and allow visitors to contact the site owner using a form.

Scenarios

  • What tourist attractions can I visit in Jinja District?
  • How can I contact tourism service providers or request more information?

Color Schema

#0B6E4F – Used for headings and navigation elements.

#F4A261 – Used for links, buttons, and accent text.

Typography

Roboto: Used for headings.

Open Sans: Used for body text.
